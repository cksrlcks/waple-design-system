Toast

방금 한 행동의 결과를 짧게 알리고 사라지는 떠 있는 알림입니다. 사용자가 시작한 작업의 결과에만 씁니다.

Anatomy

연차 신청서를 올렸습니다되돌리기
  1. Icon — filled 18px, 상태색. 뒤 배경 없음
  2. Message — 한 줄, 무엇이 됐는지
  3. Action (선택) — 링크 하나(되돌리기·보기)
  4. Close — sticky 일 때 필수

Properties

Do

Don't

Don't사용자가 시작하지 않은 시스템 소식(정기 동기화 완료 등)을 토스트로 띄우지 않습니다. 화면에 남아야 할 정보도 안 됩니다.
