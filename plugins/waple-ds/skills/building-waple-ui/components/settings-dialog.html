Settings dialog

프로필·알림·에이전트·연동·화면·계정을 한 레이어에 모은 설정 창. 사이드바의 프로필이나 「설정」을 누르면 화면 위에 뜹니다. 왼쪽은 목차, 오른쪽은 설정 행(제목·설명 + 오른쪽 컨트롤)이 이어집니다.

Guidelines

Do행 하나에 컨트롤 하나. 설명은 「무엇이 바뀌는지」 한 줄 — 「결재 알림」 아래 「내 처리 대기·반려·승인 완료」.
Don't하단에 「저장」「취소」를 두지 않습니다. 즉시 저장이 원칙이고, 되돌릴 수 없는 것(연동 해제·모두 로그아웃)만 확인 Dialog 를 겹칩니다.
Do읽기 전용 값(이메일·팀)은 Badge 로 보여 주고 왜 못 바꾸는지 설명에 적습니다.
Don'tpane 하나가 두 화면을 넘으면 pane 을 쪼갭니다 — 목차는 여덟 개까지.
