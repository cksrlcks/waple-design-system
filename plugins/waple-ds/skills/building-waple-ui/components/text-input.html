Text input

라벨 · 입력 상자 · 도움말(또는 오류)이 한 묶음. 포커스는 틸 링, 오류는 빨간 선 + 문구입니다. 한 줄이면 input, 여러 줄이면 textarea.

Anatomy

프로젝트·AS·시스템 담당자를 찾습니다
  1. Label — t1 500, 필수는 *
  2. Control — 1px 선, 라운드 sm
  3. Prefix icon (선택) — 16px muted
  4. Help / Error — t1, 오류면 fg-critical

Guidelines

Do
원 단위, 부가세 포함
라벨은 항상 위에 보이게. 형식 안내는 placeholder 가 아니라 help 에.
Don't
placeholder 를 라벨로 쓰지 않습니다 — 입력하는 순간 사라집니다.
Do오류는 그 필드 바로 아래, 무엇이 왜 틀렸고 어떻게 고치는지 한 줄.
Don't제출 버튼을 누르기 전에 빨간 선을 먼저 보이지 않습니다 — 떠날 때(blur) 또는 제출 때.
