Breadcrumb

지금 화면이 어디에 있는지 상위 단계부터 보여 주고, 한 번에 위로 올라가게 합니다. 상단 바의 「에이전트 / 홈」, 설정 창 머리의 「설정 / 알림」, 관리자 콘솔의 「직원 / 윤아린2」가 모두 이 컴포넌트입니다. 상위 단계는 링크, 마지막(현재)은 링크가 아닌 글자입니다.

Anatomy

  1. 에이전트
  2. /대화
  3. /연차 신청
  1. Leading icon (선택) — 영역 아이콘 16px. 첫 단계에만
  2. Link — 상위 단계, muted. hover 에 진해집니다
  3. Separator — 「/」 placeholder 색, 스크린리더에서 숨김
  4. Current — 지금 화면. ink, 링크 아님(aria-current="page")
  5. Collapse (넘칠 때) — 가운데 단계를 dots 버튼 하나로 접고 Menu 로 엽니다

상황규칙
네 단계 이상첫 단계와 마지막 둘만 남기고 가운데를 dots 버튼 하나로 접습니다. 접힌 단계는 Menu 항목 — 위에서 아래로 원래 순서
긴 이름링크 160px · 현재 240px 에서 한 줄 말줄임. title 에 전체 이름. 줄바꿈하지 않습니다

Guidelines

Do
  1. 설정
  2. /알림
상위 단계만 링크, 현재는 글자. 단계가 둘 이상일 때만 둡니다.
Don't
  1. 설정
  2. /알림
현재 화면을 링크로 두지 않습니다 — 눌러도 제자리이고, 어디에 있는지 흐려집니다.
Do브레드크럼은 계층입니다. 방문 순서(뒤로 가기)가 아니므로 어떤 길로 들어와도 같은 경로를 보여 줍니다.
Don't768px 아래에는 두지 않습니다 — 좁은 화면에서는 화면 머리의 뒤로 버튼과 제목이 이 일을 맡습니다.

Breadcrumb vs. Back link

BreadcrumbBack link (뒤로)
보여 주는 것전체 경로(계층)한 단계 위
자리데스크톱 상단 바 · 설정 창 · 콘솔 머리모바일 화면 머리 · 콘솔 「항목 개요」로 돌아가기
깊이2단계 이상, 4단계부터 접힘깊이와 상관없이 하나
현재 위치마지막 단계(링크 아님)화면 제목이 맡음
