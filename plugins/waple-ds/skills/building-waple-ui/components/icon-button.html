Icon button

라벨 없이 아이콘만으로 뜻이 통하는 보조 행동(첨부·닫기·더보기·이전/다음)에 씁니다. 화면을 여닫거나 목록을 넘기는 자리에 오고, 주요 행동에는 쓰지 않습니다.

Anatomy

  1. Container — 정사각형, 라운드 sm
  2. Icon — Tabler, 16·18·20px, stroke 1.75, currentColor
  3. aria-label — 보이지 않는 이름. 툴팁이 같은 문구를 보여 줍니다

State

Guidelines

Do
뜻이 굳어진 아이콘(닫기·더보기·첨부·검색·이전/다음)에만 씁니다. 항상 aria-label + 툴팁.
Don't
「결재 상신」처럼 결과가 있는 행동을 아이콘 하나에 싣지 않습니다 — 라벨 있는 Button 으로.
Do한 줄에 아이콘 버튼은 셋까지. 넷째부터는 「더보기」 메뉴로 접습니다.
Don't아이콘 크기를 상자에 맞춰 임의로 키우지 않습니다 — 16·18·20 세 값만.
