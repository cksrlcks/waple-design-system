Checkbox

목록에서 여럿을 고르거나, 하나를 켜고 끄되 저장 버튼과 함께 제출할 때 씁니다. 숨긴 native <input type="checkbox"> 위에 상자를 그려 키보드·폼 전송은 브라우저가 맡고, 켜짐은 Switch 와 같은 잉크 채움입니다.

Anatomy

  1. Input — 숨긴 native checkbox. 상태·Space·폼 전송·indeterminate
  2. Box — 16px, 1px 선, 라운드 4. 켜짐은 잉크 채움
  3. Mark — check 12px 흰색. 중간 상태는 minus
  4. Label — t2. 상자와 라벨 어디를 눌러도 토글
  5. Description (선택) — t1 muted, 라벨 아래

Guidelines

Do
라벨은 긍정형·켜지는 대상. 한 줄에 하나, 위아래로 쌓습니다.
Don't
부정형·이중 부정 라벨. 켜짐이 무슨 뜻인지 두 번 생각하게 됩니다.
Do다섯 개가 넘는 목록엔 「전체 선택」을 맨 위에 두고, 일부만 골랐을 때 중간 상태로 보여 줍니다.
Don't누르는 즉시 반영되는 설정(알림 켜기)에 쓰지 않습니다 — 그것은 Switch. 단일 「예/아니오」 질문을 라디오 둘로 늘리지도 않습니다.
