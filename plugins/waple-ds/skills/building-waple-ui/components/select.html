Select

몇 개 안 되는 선택지에서 하나를 고릅니다. 브라우저 기본 <select> 에 시스템 모양만 입혀 키보드·모바일 동작은 브라우저가 맡습니다. 항목이 스무 개를 넘거나 검색이 필요하면 Select 로 담지 않고 표·목록 화면에서 고르게 합니다.

Anatomy

시스템 설정을 따르거나 고정합니다
  1. Label — Text input 과 같은 .field 라벨
  2. Control — 36px, 1px 선, 라운드 sm
  3. Chevron — 오른쪽 16px chevron-down, muted
  4. Help (선택) — t1 muted

Guidelines

Do기본값을 첫 항목으로 두고 선택된 상태로 보여 줍니다. 「선택하세요」 빈 값은 필수 입력일 때만.
Don't항목이 둘이면 Switch·Segmented, 셋 이하로 한눈에 비교해야 하면 Radio. Select 는 4~20개.
Do설정 행·폼 모두 md(36px) — 같은 행의 Text input·Button 과 높이를 맞춥니다. 한 화면에 select 높이를 섞지 않습니다. sm 은 표 필터·툴바처럼 좁은 자리에만.
Don't커스텀 드롭다운을 새로 만들지 않습니다 — 검색·다중 선택이 필요하면 표·목록 화면에서 고르게 합니다.
