Slider

정해진 범위 안에서 값을 끌어서 고릅니다. 정확한 숫자보다 「대략 이 정도」가 중요한 설정(브리핑 알림 시각 · 답변 길이 · 회의실 인원 범위)에 씁니다. 브라우저 기본 <input type="range"> 에 옷만 입혀 키보드 조작은 브라우저가 맡습니다.

Anatomy

  3. Fill — 시작부터 thumb 까지 잉크 --bg-brand-solid

  5. Min · Max (선택) — 양 끝 값 t1 muted

State

Guidelines

Do
브리핑 알림 미리 받기10분 전
현재 값을 늘 글자로 보여 줍니다 — 「10분 전」. 끌어 놓고 무엇을 골랐는지 몰라서는 안 됩니다.
Don't
연차 1.5일처럼 정확한 값이 필요한 곳에 쓰지 않습니다 — 0.5 칸을 끌어 맞추기 어렵습니다. Number input 으로.
Do바꾸면 즉시 저장하는 설정 행(설정 · 에이전트)에 둡니다. 저장이 필요하면 놓는 순간(change)에 한 번.
Don't단계가 둘이면 Switch, 이름 있는 선택지가 여섯 이상이면 Select. 트랙에 틸을 칠하지 않습니다 — 채움은 잉크.
