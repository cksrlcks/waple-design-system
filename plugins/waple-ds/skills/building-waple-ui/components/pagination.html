Pagination

많은 결과를 쪽으로 나눠 보여 줄 때의 이동입니다. 관리자 콘솔 표는 쪽 번호(numbered)나 짧은 「‹ 2 / 14 ›」(compact)로 넘기고, 직원 앱 목록은 끝에 「더 보기」(load more)로 이어 붙입니다.

Anatomy

  1. Previous / Next — Icon button ghost. 끝에서는 disabled 로 자리를 지킵니다
  2. Page — 32px, 숫자 tabular-nums
  3. Current — 잉크 채움 + 600, aria-current="page"
  4. Gap — 건너뛴 쪽. dots 16px, 눌리지 않음

State

Guidelines

Do
칸은 7개 — 처음 · 현재 ±1 · 끝, 나머지는 생략합니다. 쪽을 넘겨도 폭과 버튼 자리가 그대로입니다.
Don't
쪽 번호를 전부 늘어놓지 않습니다 — 폭이 쪽 수만큼 늘고, 좁은 자리에서 두 줄이 됩니다.
Do직원 앱 목록은 load more — 읽던 자리를 잃지 않고, 보여 준 수(「132건 중 20건」)를 버튼 아래에 적습니다. 콘솔 표는 numbered · compact.
Don't끝에 닿았다고 이전·다음을 숨기지 않습니다 — disabled 로 두어야 다른 버튼이 제자리에 있습니다.
Do쪽을 넘기면 표 머리로 스크롤하고 포커스를 첫 행으로 옮깁니다. 쪽 크기를 바꾸면 1쪽으로 돌아갑니다.
Don't스크롤만으로 저절로 붙는 무한 스크롤을 쓰지 않습니다 — 목록 아래 푸터에 닿을 수 없게 됩니다. 사용자가 「더 보기」를 누를 때만 붙입니다.
