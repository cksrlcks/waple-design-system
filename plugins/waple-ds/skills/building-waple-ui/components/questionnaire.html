Questionnaire

에이전트가 실행 전에 확인을 받는 카드. 상신·승인·기록처럼 실제로 바꾸는 일은 이 카드가 답을 받은 뒤에만 합니다. 값이 다 있으면 요약을 보이고 승인을 받는 확인형, 모르는 값이 있으면 한 문항씩 묻는 단계형입니다. 답을 받으면 한 줄로 접혀 대화 기록에 남습니다.

Anatomy

연차를 신청할까요?

에이전트가 채운 값입니다. 승인하면 결재를 올리고, 올린 뒤에도 결재함에서 취소할 수 있습니다.

  2. Summary — Dialog 와 같은 요약 상자(.dialog-sum). 에이전트가 채운 값 그대로
  3. Footer — 오른쪽 정렬. 주요 행동 하나(잉크) + 「수정」 outline + 「취소」 weak
  4. Band (선택) — 예시 데이터일 때 맨 위 sample 띠
  5. Progress · Question · Options — 단계형에서 Summary 자리에 오는 셋(아래 Type)

State

Guidelines

Do
주요 행동은 잉크 하나, 오른쪽 끝. 「승인」「제출」처럼 무엇이 일어나는지 라벨에 적습니다.
Don't
틸 알약에 흰 글자(앱의 지금 모양 — 대비 2.1:1) · 「확인」「예」 라벨.
Do카드는 턴에 하나, 답을 받으면 접습니다. 단계형은 3문항 안쪽 — 그 이상이면 대화로 묻습니다. 사용자가 카드를 두고 다른 말을 하면 「취소됨」으로 접고 새 말에 답합니다.
Don't답을 받은 카드를 열린 채 두지 않습니다(다시 누를 수 있어 보입니다). 확인 없이 상신하지 않습니다. 한 카드에 문항 여럿을 쌓거나, 카드 위에 Dialog 를 또 띄우지 않습니다.
