Input group

Text input 한 칸에 아이콘 · 단위 · 버튼 · 셀렉트를 붙인 묶음. 선도 하나, 포커스 링도 하나 — 묶음 전체가 한 입력처럼 보입니다. 라벨 · 도움말 · 오류는 Text input(.field)을 그대로 씁니다.

Anatomy

이름 · 팀 · 시스템으로 찾습니다
  1. Group — .ctrl 하나: 1px 선 · 라운드 sm · :focus-within 링
  2. Leading (선택) — 16px 아이콘, 셀렉트, 또는 앞 글자
  3. Input — 남는 폭을 모두 차지
  4. Inline action (선택) — 지우기 · 보기 · 로딩, 28px ghost
  5. Edge button (선택) — 오른쪽 끝에 붙은 버튼, 선 하나로 가름

State

Guidelines

Do
원
단위는 값 밖에 붙입니다 — 사용자는 숫자만 칩니다.
Don't
단위를 값에 섞어 받지 않습니다 — 「45,000원」은 숫자 검증이 깨집니다.
Do입력에 딸린 행동만 붙입니다(검색 · 복사). 폼 전체의 제출은 아래 Button 으로.
Don't부품마다 선 · 링을 따로 두지 않습니다. 붙은 버튼에 잉크를 칠하지 않습니다 — 화면의 주요 행동은 따로 있습니다.
