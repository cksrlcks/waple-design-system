Image frame

사진·스캔 한 장을 담는 틀. 비율(aspect-ratio)과 맞춤(object-fit)을 정하고, 안쪽 1px 선으로 흰 영수증·문서가 흰 바탕에 번지지 않게 합니다. 불러오는 중·깨짐도 이 틀이 맡습니다.

Anatomy

  1. Frame — 비율 · 라운드 · --bg-neutral-weak 바탕(불러오기 전·contain 여백)
  2. Image — object-fit cover(기본) 또는 contain
  3. Stroke — 안쪽 1px --stroke-neutral-strong, multiply 로 섞음
  4. Caption (선택) — t1 muted, 틀 아래 8px

Properties

Ratio

비율쓰임
1:1썸네일·첨부 격자·말풍선 안 사진
4:3영수증·현장 사진 기본
16:9카드 머리·회의실 사진·화면 캡처
free원본 비율 그대로 — 상세 보기 한 장. 폭만 정합니다

Fit

맞춤쓰임
cover (기본)사진 — 회의실·현장. 가장자리가 잘려도 뜻이 남는 것
contain문서·영수증 — 합계·도장·서명이 잘리면 안 되는 것

Radius

라운드쓰임
sm행·목록 안, 56px 이하 썸네일
md기본 — 첨부·본문 사진
lg단독 사진·캐러셀 — 카드(radius-lg)와 같은 곡률

Size — 썸네일

크기라운드쓰임
28xs첨부 칩·말풍선 안
40sm파일 행(설정 「첨부」)
56md컴포저 첨부 타일
72 · 96md첨부 격자·영수증 목록

State

상태표현
loading틀 크기 그대로 Skeleton(shimmer). 비율을 먼저 잡아 두어 사진이 와도 화면이 튀지 않습니다
broken--bg-neutral-weak + photo 아이콘 --fg-neutral-muted(40px 이하는 photo-filled 16px). 누르면 다시 불러옵니다

Guidelines

Do
흰 스캔·영수증도 틀의 바탕과 안쪽 선이 경계를 그려 줍니다.
Don't
틀 없이 넣은 흰 이미지는 바탕으로 번져 크기와 경계가 보이지 않습니다.
Doalt 에는 내용을 씁니다 — 「9월 7일 점심 영수증, 12,000원」. 꾸밈 사진은 alt="".
Don'talt="image.png" · 「사진」처럼 파일 이름이나 종류만 적지 않습니다. 캡션과 같은 말을 되풀이하지도 않습니다.
Do문서·영수증은 contain — 합계·도장이 잘리지 않게.
Don't틀에 맞추려고 사진을 늘리거나(fill) 비율을 바꾸지 않습니다.
