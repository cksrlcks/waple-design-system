Guidelines

Do

이번 주 업무일지가 없습니다

연동 소스로 초안을 자동 작성합니다.

비었으니 무엇을 하면 되는지 — 다음 행동을 CTA 로 줍니다.
Don't

데이터가 없습니다

「데이터 없음」「No data」처럼 상태만 적고 끝내지 않습니다.
Do오류엔 원인 한 줄 + 「다시 시도」. 연동 안 됨엔 연동하면 얻는 것을 적습니다.
Don't큰 일러스트·긴 설명으로 채우지 않습니다. 결과 없음에 brand-solid 를 쓰지 않습니다 — 주요 행동이 아닙니다.
