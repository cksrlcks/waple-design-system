Tag group

한 대상의 속성 두셋(팀 · 직급 · 상태, 형식 · 용량 · 날짜)을 가운뎃점으로 이어 한 줄에 놓는 메타 글줄입니다. 배경도 선도 없어 제목 아래 · 행 오른쪽 어디에나 놓입니다. 점은 CSS 가 그리고 스크린리더에는 쉼표로 읽힙니다.

Anatomy

디자인1팀부장자리 비움
  1. Item — 짧은 명사 하나, 줄바꿈 없음
  2. Separator — 「·」 ::before, 첫 항목에는 없음. 대체 텍스트 「, 」
  3. Leading icon (선택) — 14px(md 16px) filled, 글자 앞 4px
  4. Ellipsis — 자리가 모자라면 끝에서 말줄임. 잘리는 것은 늘 뒤쪽 항목

Guidelines

Do
디자인1팀부장자리 비움
식별에 중요한 것부터 — 팀 · 직급 · 상태. 셋 안쪽, 상태는 글자 + 아이콘.
Don't
디자인1팀부장자리 비움
속성마다 Badge 를 칠하지 않습니다 — 배경 셋이 제목보다 눈에 띕니다. 배지는 상태 하나에.
Do항목은 짧은 명사 — 「3.0MB」 「9월 7일」 「자리 비움」. 단위 · 날짜 형식은 시스템대로.
Don't문장(「지금 자리를 비웠습니다」)이나 항목 안의 쉼표 · 점(「디자인1팀, 부장」). 점은 하나뿐입니다.
