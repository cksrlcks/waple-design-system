Button

사용자가 행동을 실행하게 하는 가장 기본적인 요소. 화면의 주요 행동은 brand-solid(검정) 하나만 씁니다. 틸 채움 버튼은 없습니다 — 틸은 글로우 CTA(Composer)와 선택 상태에만.

Anatomy

  1. Container — 크기·라운드·배경을 가진 상자(버튼 전체)
  2. Prefix icon (선택) — 라벨 앞 아이콘. xs 14 · sm 16 · md 18 · lg 20px
  3. Label — 동사로 끝나는 짧은 문구
  4. Suffix icon (선택) — 방향·펼침을 뜻할 때만

Guidelines

Do
주요 행동은 오른쪽(또는 아래), 취소는 낮은 강조로.
Don't
solid 두 개를 나란히 두지 않는다 — 무엇이 주요 행동인지 알 수 없다.
Do라벨은 동사로 끝낸다: 예약하기 · 저장 · 삭제.
Don't「확인」「OK」「예」처럼 무엇이 일어나는지 모르는 라벨.
