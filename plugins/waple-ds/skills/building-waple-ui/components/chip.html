Chip

목록을 좁히는 필터, 그리고 「이렇게 물어보셔도 됩니다」의 제안 프롬프트. 알약 모양이고, 눌러도 화면을 떠나지 않습니다.

Anatomy

결재가 반려됐는데 누구한테 물어봐야 해?
  1. Container — 알약(radius-full), 1px 선
  2. Leading (선택) — 제안 칩의 sparkles 아이콘 14px (틸)
  3. Label — 한 줄, 줄바꿈 없음
  4. Count (선택) — 필터 결과 수, muted

Guidelines

Do
전체승인 대기반려
필터 칩은 한 줄에 두고, 「전체」를 첫 자리에. 선택은 항상 하나 이상.
Don't
내 예약
선택 상태에 틸을 칠하지 않습니다 — 틸은 강조 한 곳(글로우·포커스)에만.
Do제안 칩 문구는 사용자가 실제로 칠 문장 그대로(「이번주 근태 어때?」).
Don't칩으로 페이지를 이동시키지 않습니다 — 이동은 Button·링크.
