Dialog

에이전트가 실행하기 전에 무엇을 할지 확인받는 창입니다. 화면을 멈추고 답을 받아야 할 때만 씁니다.

Anatomy

연차를 신청할까요?

아래 내용으로 연차 신청서를 올립니다. 상신 뒤에도 결재함에서 취소할 수 있습니다.

항목연차 신청
날짜9/10 (수) · 1일
결재선김부장 → 인사팀
  1. Title — 질문형 한 줄(t4 Semibold)
  2. Body — 결과와 되돌리는 방법(t2 subtle)
  3. Summary (선택) — 에이전트가 실행할 값을 라벨·값 쌍으로
  4. Footer — 오른쪽 정렬, 취소(outline) + 주요 행동(solid) 하나

알림

계속하시겠습니까?

무엇을 하는지 모르는 제목·「예/아니오」, solid 두 개.
Do닫는 길 셋을 모두 엽니다 — ESC·배경 클릭·취소 버튼은 같은 「취소」. 열리면 포커스는 창 안 첫 버튼(취소)으로 가고 Tab 은 창 안에서만 순환합니다.
Don't정보만 보여 주려고 Dialog 를 열지 않습니다(Notice·Toast 로). Dialog 위에 Dialog 를 겹치지 않습니다.
