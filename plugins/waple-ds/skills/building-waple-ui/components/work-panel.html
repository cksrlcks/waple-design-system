Work panel

카드에서 다 담지 못하는 선택을 대화 안에서 이어 받는 패널. 사용자의 말풍선 아래에 붙고, 값을 다 고르면 아래쪽 한 버튼으로 상신합니다 — 실행 전 확인과 같은 규칙입니다.

Anatomy

일월화수목금토

시작일을 누르고 종료일을 한 번 더 누르면 기간이 잡힙니다. 주말·공휴일은 일수에서 빠집니다.

사유
신청 3일 · 잔여 12일 → 9일
  1. Message — 무엇을 부탁했는지 한 줄. 오른쪽 정렬
  2. Header / Stats — 이름 + 잔여, 그리고 결정에 필요한 숫자를 알약으로
  3. Summary — 고른 기간을 글로 되돌려 준다. 달력만 보고 셈하지 않게
  4. Preset — 가장 흔한 기간 두세 개. 달력을 열지 않고 끝난다
  5. Calendar — 월 달력. 시작 → 끝 두 번 눌러 기간을 잡는다
  6. Footer — 신청 일수와 남게 될 잔여 + 주요 버튼 하나

Properties

날짜 고르기 — 시작 → 끝

첫 번째 누름이 시작, 두 번째 누름이 끝입니다. 사이는 저절로 채워지고, 세 번째 누름은 다시 시작이 됩니다. 끝을 고르기 전에는 가리키는 날까지 미리 칠해 어디까지 잡히는지 보여 줍니다. 하루만 쓸 때는 Preset 이나 카드의 주간 달력으로 끝납니다.

칸표현
기본38px 칸 · 숫자는 32px 원 안에
오늘--stroke-accent 원 테두리 + --fg-accent
시작 · 끝--bg-brand-solid 원 채움. 사이 띠는 원 가운데에서 시작해 이어진다
사이--bg-neutral-weak 띠. 칸 사이 간격이 0 이어야 띠가 끊기지 않는다

지난 날--fg-disabled · 누를 수 없음

Footer

상태표현
덜 골랐을 때무엇을 더 골라야 하는지 한 줄(「날짜를 고르세요」). 주요 버튼 없음
다 골랐을 때「신청 3일 · 잔여 12일 → 9일」처럼 남게 될 값까지 + brand-solid 버튼 하나. 옆에 「지우기」
보낸 뒤요약 자리에 결과 문구, 버튼은 사라짐. 되돌리기는 Toast 로

Guidelines

Do고른 기간을 글로 다시 적고, 신청 뒤 남게 될 잔여까지 보여 줍니다 — 셈은 화면이 합니다.
Don't「연속 3일」처럼 일수만 고르게 하지 않습니다. 며칠이 아니라 어느 날이 결정입니다.
Do패널 하나에 결정 하나. 연차 신청이면 기간·사유까지만 담습니다.
Don't카드에서 이미 고른 값을 다시 묻지 않습니다 — 넘어올 때 채워 둡니다.
Do고를 수 없는 값(주말·지난 날·잔여 없음)은 흐리게 두고 왜인지 달력 아래에 적습니다.
Don't패널 안에 「취소」를 따로 두지 않습니다 — 닫기 ×, 되돌리기는 「지우기」, 상신은 버튼 하나.
