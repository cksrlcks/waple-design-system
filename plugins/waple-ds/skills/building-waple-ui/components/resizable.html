Resizable

두 영역 사이의 선을 끌어 폭(높이)을 나눕니다. 홈의 대화 | 컨텍스트 패널(기본 320, 280–520)과 콘솔의 워크플로 캔버스 | 속성 패널에 씁니다. 끈 폭은 기억하고, 선을 두 번 누르면 기본값으로 돌아갑니다.

Anatomy

대화연차 잔여 현황을 알려 줘 — 잔여 11일, 이번 달 사용 1일입니다.
컨텍스트 패널기본 320px · 끌어서 280–520
  1. Pane — 나뉜 영역. 내용은 pane 안에서 스크롤합니다
  2. Handle — 1px 선 + 양쪽 4px 씩 8px 누름 영역. hover·끌기에 accent 2px, 커서 col-resize
  3. Grip (선택) — 12×24 손잡이 + grip 아이콘 12px
  4. Sized pane — 크기를 가진 쪽(컨텍스트 320). 반대쪽은 남은 폭을 채웁니다

Guidelines

Do기본·최소·최대를 정하고, 끈 폭은 기억하고, 두 번 누르면 기본값으로 — 홈 컨텍스트 패널이 이 규칙입니다.
Don't최소 없이 끝까지 줄이게 두지 않습니다 — 글이 한 글자씩 꺾이는 폭이 생깁니다. 반대쪽(대화 열)의 최소 폭도 지킵니다.
Do가끔 끄는 앱 셸 경계는 선만, 자주 끄는 편집 화면은 grip 을 둡니다.
Don't1280px 아래·터치 화면에 핸들을 두지 않습니다 — 그 폭에서 컨텍스트 패널은 Sheet(오른쪽 360)로 바뀝니다(계획서 §7.1).
