Number input

− 값 + 로 정확한 수를 한 step 씩 바꾸고, 가운데를 눌러 직접 칠 수도 있습니다(seed 의 Quantity picker). 연차 1.5일처럼 업무 규칙이 정한 단위(반차 0.5일)가 있는 값에 씁니다.

Anatomy

반차(0.5일) 단위 · 잔여 11일
  1. Container — 1px 선 · 라운드 sm · md 36px
  2. Decrement — 28px ghost iconbtn(minus). 최솟값이면 disabled
  3. Value — 기본 <input type="number">, t2 600 tabular. 직접 입력
  4. Unit (선택) — 일 · 명, muted
  5. Increment — plus. 최댓값이면 disabled

Guidelines

Do
반차(0.5일) 단위 · 잔여 11일
step 은 업무 규칙대로(반차 0.5). 범위는 help 에 글로 적습니다.
Don't
금액처럼 범위가 넓은 값은 누르기로 못 닿습니다 — 단위 붙은 Input group 으로.
Do끝에 닿으면 버튼을 disabled 로 — 누를 수 있어 보이는데 아무 일도 없으면 고장처럼 보입니다.
Don't24 를 친 순간 조용히 20 으로 바꾸지 않습니다 — 떠날 때 오류로 알리고 사용자가 고칩니다.
