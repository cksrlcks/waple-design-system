Segmented control

같은 자리에서 보기를 바꾸는 2~4개의 선택지(수신함 47 / 발신함 50). 알약 컨테이너 안에서 선택된 항목만 흰색으로 떠 있습니다.

Anatomy

  1. Container — 알약, --bg-neutral-weak, 3px 패딩
  2. Item — 라벨 t1 500 + 건수 muted
  3. Selected — 흰 배경 + shadow-1 + 600

Properties

Size

State

Guidelines

Do항목은 2~4개, 라벨은 한두 단어. 건수는 라벨 뒤에 muted.
Don't다섯 개 이상이면 Tabs 나 Select 로. 항목 폭이 서로 크게 다르면 안 됩니다.
Do바꾸면 즉시 아래 내용이 바뀝니다 — 저장·확인 버튼 없음.
Don't선택 항목에 틸·검정을 칠하지 않습니다 — 흰색 + 그림자가 「눌려 올라옴」을 뜻합니다.
