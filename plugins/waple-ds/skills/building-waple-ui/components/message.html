Message

대화의 한 턴. 사용자는 오른쪽 말풍선(Bubble), 에이전트는 말풍선 없이 열 폭의 본문으로 답하고, 일을 하는 동안에는 실행 카드 → 완료 카드 → 후속 칩으로 이어집니다. 아바타 · 머리(이름·시각) · 내용 · 발(행동) 네 자리의 조합입니다.

Anatomy

에이전트오후 2:08

네, 9월 14일(월)에 연차를 쓸 수 있습니다. 잔여 연차는 12일입니다.

  • 그날 10:00 주간 회의 1건과 겹칩니다
  • 결재선: 김팀장 → 박본부장

이대로 신청서를 올릴까요?

  1. Avatar (선택) — 28px. 1:1 에이전트 대화에서는 생략하고, 사람이 섞이는 스레드에서만
  2. Header (선택) — 이름 t1 600 + 시각 t1 muted. 묶음의 첫 메시지에만
  3. Bubble — 사용자 글. --bg-neutral-weak, 오른쪽 아래 모서리만 xs, 최대 78%
  4. Content — 에이전트 답. 말풍선 없이 마크다운 t3, 최대 720px
  5. Footer — 복사 · 다시 생성 · 좋아요/싫어요 ghost iconbtn sm. hover · 키보드 포커스 · 마지막 메시지에만

Guidelines

Do
후속 칩의 primary 는 하나, 잉크 채움. 누르면 그 문장이 바로 보내집니다.
Don't
틸로 칠하거나(앱의 지금 모양) primary 를 둘 두지 않습니다.
Do사용자 글만 말풍선에 넣습니다. 에이전트 답은 본문이라 표·목록이 말풍선 폭에 갇히지 않습니다. 실행 카드는 끝나면 접고, 결과는 완료 카드와 답이 말합니다.
Don't타이핑 점과 진행 줄(Marker)을 함께 그리지 않습니다 — 점이 두 줄로 겹칩니다. 에이전트 답에 틸 배경 말풍선을 입히지 않습니다(그건 Agent notice).
