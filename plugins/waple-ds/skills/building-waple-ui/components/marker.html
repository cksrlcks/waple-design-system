Marker

대화 사이에 끼는 한 줄 표식 — 지금 무엇을 하는지(진행), 무엇이 바뀌었는지(시스템 메모), 어디서 날이 바뀌는지(구분선). 말풍선도 카드도 아닌 가장 조용한 층입니다. 진행 표식은 실행이 열려 있는 동안 반드시 보이고, 사라지는 것이 「끝났다」는 신호입니다.

Anatomy

근태 기록 조회 중3초
  1. Indicator — 진행 점 6px(accent 깜빡임) · 타이핑 점 · 아이콘 16 중 하나
  2. Text — t1 --fg-neutral-subtle, 지금 하는 일을 「~ 중」으로
  3. Meta (선택) — 경과·시각 t1 muted, tabular
  4. Action (선택) — 「중단」 btn xs outline 하나

Guidelines

Do
결재선 확인 중4초
진행 표식은 목록 맨 아래 한 줄. 경과 시간과 「중단」을 같이 두어 기다릴지 스스로 판단하게 합니다.
Don't
처리 중…
무엇을 하는지 없는 「처리 중」, 끝났는데 남아 있는 진행 표식.
Do구분선은 날짜가 바뀔 때만, 시스템 메모는 사용자가 한 행동의 결과(취소·수정)만 남깁니다.
Don'tMarker 에 상태색 배경을 칠하거나 배지처럼 쓰지 않습니다 — 상태를 붙일 대상이 있으면 Badge.
