Popover

트리거 옆에 뜨는 비모달 패널입니다. Tooltip 보다 풍부한 내용 — 설명과 링크, 한 칸짜리 빠른 편집, 필터, 프로필 — 을 담고, 열려 있어도 뒤 화면을 그대로 쓸 수 있습니다. 행동 목록은 Menu, 화면을 멈추고 확인받을 것은 Dialog 입니다.

Anatomy

회의 제목
  1. Trigger — 클릭으로 엽니다. aria-haspopup="dialog" · aria-expanded, 열린 동안 .selected
  2. Arrow (선택) — 트리거가 아이콘 버튼일 때만. CSS 로 돌린 10px 정사각
  3. Header (선택) — 제목 t3 600 + 닫기 iconbtn sm
  4. Body — 설명(t2 subtle) · 입력 · 칩 · 스위치
  5. Footer (선택) — sm 버튼, 주요 행동은 brand-solid 하나

Guidelines

Do

반차는 0.5일로 셉니다. 오전·오후를 고를 수 있습니다.

연차 규정 보기
설명은 두세 문장 + 링크 하나. 바깥 클릭으로 닫힙니다.
Don't
안내

9월 지출결의는 9/25 까지 상신해야 합니다. 늦으면 다음 달로 넘어가며 영수증을 다시 첨부해야 합니다.

읽고 「확인」해야 하는 내용은 Dialog, 늘 보여야 하는 마감·경고는 Notice 로.
Do입력은 한두 칸 — 회의 제목·사유처럼. 필드가 셋을 넘거나 검증이 길면 Dialog·작업 패널로 옮깁니다.
Don't팝오버 안에서 팝오버·메뉴를 또 열거나, 패널 안에 스크롤을 만들지 않습니다.
Dohover card 는 지름길입니다 — 같은 정보가 이름을 누르면 여는 화면에도 있어야 터치·키보드 사용자가 볼 수 있습니다.
Don't고친 입력이 바깥 클릭 한 번에 사라지게 하지 않습니다. 바뀌었으면 바깥 클릭은 무시하고 Esc·취소로만 닫습니다.
