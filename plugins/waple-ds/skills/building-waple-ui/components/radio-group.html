Radio group

2~5개 중 하나만 고르고, 선택지를 전부 보여 비교하게 할 때 씁니다(연차 종류 · 결재 방식). native <input type="radio"> 를 숨기고 점만 그려, 화살표 키 이동과 「항상 하나는 선택」은 브라우저가 맡습니다.

Anatomy

연차 종류
  1. Fieldset · Legend — 질문(라벨). 묶음이 곧 하나의 Field
  2. Input — 숨긴 native radio. 같은 name 이 한 묶음
  3. Dot — 16px 원, 켜지면 잉크 채움 + 흰 점 6px
  4. Label — t2. 점과 라벨 어디를 눌러도 선택
  5. Description (선택) — t1 muted

Guidelines

Do
결재 방식
기본값을 하나 골라 둡니다. 「선택 안 함」이 뜻이 있으면 그것도 항목으로.
Don't
알림
「켜기 / 끄기」 둘뿐이면 라디오가 아니라 Switch(즉시) 또는 Checkbox(제출).
Do항목 사이 비교가 핵심이면 card — 일수·시간처럼 숫자를 설명에 넣습니다.
Don't여섯 개를 넘으면 Select. 화면에 라디오가 스무 개 늘어서면 읽지 않습니다.
