Switch

켜고 끄는 즉시 반영되는 설정(알림 · 자동 초안 · 연동). 저장 버튼이 따로 필요하면 Checkbox 입니다.

Anatomy

  1. Track — 40×22, 알약. 켜짐은 검정
  2. Thumb — 16px 흰 원, shadow-1
  3. Input — 숨긴 <input type="checkbox">. 상태·키보드·폼 전송을 브라우저가 처리합니다
  4. Label — 오른쪽, t2. 무엇이 켜지는지 명사로

Properties

Size

크기쓰임

State

Guidelines

Do
라벨은 켜지는 대상(「결재 알림」). 누르는 즉시 적용되고 토스트로 알립니다.
Don't
부정형 라벨 금지 — 켜짐이 「안 받음」이 되면 헷갈립니다.
Do되돌릴 수 없는 것(연동 해제)은 스위치 뒤에 확인 Dialog 를 둡니다.
Don't여러 스위치를 바꾼 뒤 「저장」을 누르게 하지 않습니다 — 그 경우는 Checkbox + 버튼.
