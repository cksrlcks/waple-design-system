Guidelines

Do순서는 고정: 새 대화 → 에이전트 → 현황 → 사내 시스템 → 대화 → 사용자. 사내 시스템 항목은 설정에서 켠 것만.
Don't항목에 틸 배경이나 굵은 왼쪽 막대를 두지 않습니다 — 선택은 회색 채움 하나로.
Do레일 상태에서는 모든 항목에 툴팁(오른쪽) — 라벨이 사라졌으니까.
Don't사이드바 안에 스크롤 영역을 둘 만들지 않습니다 — 본문 하나만 스크롤, 상단·사용자는 고정.
