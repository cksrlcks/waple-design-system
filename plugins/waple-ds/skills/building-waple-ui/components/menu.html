Menu

kebab(⋯)·버튼·우클릭으로 여는 행동 목록입니다. 행·카드·표에서 자리를 차지하지 않고 보조 행동을 모아 두었다가, 고르면 바로 실행하고 닫힙니다. 값을 고르는 것은 Select, 설명·입력은 Popover 입니다.

Anatomy

  1. Trigger — ghost 아이콘 버튼. aria-haspopup="menu" · aria-expanded, 열려 있는 동안 .selected
  2. Container — role="menu". 떠 있는 면 · 1px 선 · shadow-2 · radius-md, 폭 200~320
  3. Item — role="menuitem" 36px: 아이콘 18 · 동사 라벨 · 뒤(단축키·체크·›)
  4. Separator — 성격이 다른 묶음 사이 <hr>, 좌우 끝까지
  5. Destructive — 맨 끝, 선 아래, critical 글자. 누르면 확인 Dialog
  6. Group label (선택) — 묶음이 둘 이상일 때만. 아래 Item 참고

Guidelines

Do
파괴적 행동은 맨 끝, 선 아래. 누르면 확인 Dialog 를 엽니다.
Don't
삭제를 맨 위·중간에 두지 않습니다 — 손이 먼저 닿는 자리입니다.
Do항목은 3~7개. 여덟 개가 넘으면 묶음 라벨로 나누거나 목록·설정 화면으로 옮깁니다.
Don't항목 하나짜리 kebab — 그 행동을 버튼으로 바로 보여 줍니다. kebab 은 보조 행동이 2개 이상일 때만.
Do주요 행동은 밖에. 결재 행의 「승인」은 버튼, kebab 에는 링크 복사·회수 같은 보조만 넣습니다.
Don't화면의 주요 행동을 메뉴에 숨기지 않습니다 — 사용자는 메뉴를 열어 보지 않습니다.
Do라벨은 동사: 이름 바꾸기 · 고정 · 보관 · 삭제. 대상은 행이 이미 말하므로 되풀이하지 않습니다.
Don't「설정」「기타」「관리」처럼 무엇이 일어나는지 모르는 명사, 「대화 삭제」처럼 대상을 반복하는 라벨.
Do지금 못 하는 항목은 disabled 로 남기고 이유를 알립니다 — 자리가 매번 바뀌면 위치를 외울 수 없습니다.
Don't하위 메뉴를 두 단계 이상 겹치거나, 한 화면에서 dots 와 dots-vertical 을 섞지 않습니다.
