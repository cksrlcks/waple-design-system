Guidelines

Do숫자·금액·일시는 오른쪽 정렬 + tabular-nums. 단위는 헤더에(금액(원)).
Don't행마다 버튼을 여럿 두지 않습니다 — 액션 열은 「더보기」 하나, 나머지는 행 선택 후 상단 툴바.
Do첫 열은 그 행을 알아보게 하는 이름(문서 제목)이고 굵게. 나머지는 400.
Don't줄무늬(zebra)·세로 선을 넣지 않습니다. 행 구분은 --stroke-neutral 한 줄과 hover 로 충분합니다.
