Skeleton

내용이 오기 전에 화면 구조를 먼저 그려 두는 회색 자리표시입니다. 1–3초 구간의 첫 로딩에만 씁니다.

Anatomy

  1. Block — --stroke-neutral-strong 바탕의 자리표시, 실제 요소와 같은 크기
  2. Shimmer — 왼쪽에서 오른쪽으로 한 번씩 지나가는 밝은 띠(1.4초)
  3. Layout — 실제 컴포넌트와 같은 컨테이너·간격

Properties

Shape

Shape크기흉내내는 것
text높이 14px · 폭 부모 또는 지정본문·제목 한 줄(마지막 줄은 60–80%)
line높이 8px · 알약캡션·라벨
circle36px아이콘 칩·아바타
card높이 120px · radius-lg이미지·차트·버튼(크기 지정)

Composition

빠른 실행 카드 스켈레톤 — 아이콘 칩 36px · 제목 한 줄 · 설명 한 줄 · 하단 sm 버튼 자리. 실제 카드와 컨테이너(라운드 lg · 선 strong · 패딩)를 같이 씁니다.

Guidelines

Do
구조를 흉내냅니다 — 줄 수·아이콘 자리·폭이 실제 내용과 같게.
Don't
큰 회색 상자 하나로 덮지 않습니다. 실제와 달라 내용이 오면 화면이 튑니다.
Do1–3초 구간에만. 0.3초 안에 오면 아무것도 보이지 않고, 3초를 넘기면 「불러오는 중」 문구, 10초를 넘기면 정형 Progress + 취소(Loading).
Don't새로고침·더 불러오기에 스켈레톤을 쓰지 않습니다 — 기존 내용은 유지하고 Progress circle 을 씁니다. 스켈레톤 위에 글자를 얹지 않습니다.
