Badge

상태 한 단어(승인 대기 · 반려 · 연결됨)나 건수(6)를 붙이는 작은 표식. 눌리지 않고, 여섯 상태 어휘의 색을 그대로 씁니다.

Anatomy

승인 대기

  2. Label — 12px 600, 두 단어 이하. 뜻은 항상 글자에 (색만으로 전하지 않습니다)
