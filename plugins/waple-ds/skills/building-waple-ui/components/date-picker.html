Guidelines

DoFooter 에 고른 날짜를 요약합니다(9/14 – 9/16 · 3일). 사용자가 셈하지 않게 일수를 붙입니다.
Don't팝오버 안에 「확인」 버튼을 두지 않습니다 — 날짜를 누르면 곧 값입니다. 실행 확인은 폼의 버튼·Dialog 가 합니다.
Do주말·공휴일·마감 지난 날은 off 로 보여 주고, 왜 안 되는지 툴팁으로 알립니다.
Don't날짜 하나를 고르는 단순 폼에 이 컴포넌트를 쓰지 않습니다 — <input type="date"> 로 충분합니다.
