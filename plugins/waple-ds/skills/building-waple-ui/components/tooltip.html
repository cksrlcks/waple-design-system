Tooltip

아이콘 버튼처럼 라벨이 없는 요소에 마우스를 올리거나 포커스하면 이름을 보여 주는 짧은 말풍선입니다.

Anatomy

파일 첨부
  1. Container — 잉크 배경, 12px Medium, radius-sm
  2. Arrow — 4px, 트리거 가운데를 가리킵니다
  3. Trigger — 아이콘 버튼·잘린 글자·상태 점

Guidelines

Do한두 단어. 300ms 지연으로 스쳐 지나갈 때 깜빡이지 않게 합니다.
