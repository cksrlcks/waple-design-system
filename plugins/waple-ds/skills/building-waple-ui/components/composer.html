Composer

에이전트에게 말을 거는 입력창. 화면 하단에 하나만 있고, 오른쪽의 글로우 CTA 는 이 시스템에서 틸을 채우고 흰 글자를 쓰는 유일한 자리입니다.

Anatomy

  1. Textarea — t3, 자동 높이, 라벨 없음(placeholder 가 안내)
  2. Attach — outline iconbtn
  3. Plan — 「계획 세우기」 sm outline: 바로 실행 대신 계획부터
  4. Glow CTA — 「에이전트에게 맡기기」 gradient + glow

Guidelines

DoEnter 로 전송, Shift+Enter 로 줄바꿈. placeholder 에 그 사실을 적습니다.
Don't글로우 CTA 를 화면에 둘 두지 않습니다. 컴포저 밖의 「맡기기」는 검정 Button.
Do글로우 위 흰 글자는 15px 600 이상 — AA large(3:1) 기준을 넘기는 최소 크기입니다.
Don'tCTA 를 sm 으로 줄이거나 글자를 t2 로 낮추지 않습니다. 줄여야 하면 아이콘 전용 solid iconbtn 으로.
