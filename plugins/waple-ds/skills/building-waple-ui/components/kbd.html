Kbd

단축키를 알려 주는 키 캡입니다. 누르는 버튼이 아니라 읽는 표시라서 배경 없이 선만 긋습니다. 문서 사이트 검색창 끝의 「Ctrl K」가 이 모양입니다.

Anatomy

CtrlK
  1. Cap — 1px --stroke-neutral-strong 선, --radius-xs, 배경 없음
  2. Label — t1 400 muted. 키보드에 새겨진 이름 그대로
  3. Group (조합) — 캡을 4px 간격으로 나란히 두고 바깥 <kbd> 로 묶습니다
  4. Icon (선택) — 13px. command · 화살표처럼 글자가 없는 키

운영체제는 처음 한 번 정하고 화면 전체가 같은 표기를 씁니다. 한 화면에 Ctrl 과 command 를 섞지 않습니다.

In context

Guidelines

Do키 이름은 키보드에 새겨진 영어 그대로 — Ctrl · Shift · Enter · Esc. 조합은 캡을 나누고, 좁은 자리에서만 한 캡으로 합칩니다.
Don't「컨트롤」「엔터」처럼 한글로 풀어 쓰지 않습니다. macOS 기호를 글자로 넣지 않습니다 — 글꼴마다 모양이 달라 command 는 아이콘으로 씁니다.
Do단축키는 찾을 수 있는 자리에 둡니다 — 메뉴 항목 끝, 툴팁, 명령 팔레트 푸터.
Don't단축키를 유일한 방법으로 두지 않습니다. 브라우저가 쓰는 조합(Ctrl T · W · L · R)과 겹치게 정하지 않습니다.
