Agent notice

에이전트가 무엇을 해 주는지, 지금 상태가 어떤지 화면 위쪽에 놓는 사라지지 않는 안내. 틸 틴트 말풍선이며 화면에 하나만 둡니다.

Anatomy

근태·연차·결재·업무일지·일정·경비를 대신 처리합니다.
업무 협조가 필요할 때는 프로젝트·AS·시스템 담당자를 찾아 지금 자리에 있는지 확인하고 바로 메시지까지 보내드립니다.
  1. Icon — sparkles 16px, 역할 색
  2. Lead — 첫 문장 600
  3. Body — t2, 두 줄 이내

Properties

Variant

에이전트가 조회와 초안 작성까지 스스로 수행합니다. 상신·승인·기록은 확인 버튼을 받은 뒤에만 실행합니다.
근태 시스템 연동이 끊겨 있습니다. 출퇴근 기록은 복구될 때까지 저장되지 않습니다.
예시 데이터입니다. 연동을 켜면 실제 근태·결재 수치로 바뀝니다.

Guidelines

Do첫 문장에 결론(무엇을 해 준다 / 무엇이 안 된다), 둘째 문장에 조건. 두 줄이면 끝.
Don't닫기 × 를 두지 않습니다 — 닫혀야 하는 알림은 Toast, 확인이 필요한 것은 Dialog.
Do화면에 하나. 둘이 필요하면 더 급한 warning 하나만 남깁니다.
Don't버튼을 넣지 않습니다. 행동이 필요하면 아래 카드·컴포저로 유도하는 문장으로.
