Progress

작업이 얼마나 진행됐는지(determinate) 또는 진행 중이라는 사실(indeterminate)을 보여 줍니다. 모양은 막대 · 원 · 스피너 셋이고, 막대가 기본입니다. 설정 「첨부」의 용량 막대(Settings dialog)도 Progress bar md · neutral 입니다.

Anatomy

업무일지 초안 작성3 / 5단계
  1. Label — 무엇이 진행 중인지, t1 subtle
  2. Value — 「3 / 5단계」「62%」, t1 600 tabular-nums. 오른쪽 끝
  3. Track — 전체 길이, --bg-neutral-weak 알약
  4. Indicator — 진행분, 톤 색. 최소 6px 라서 1% 도 보입니다

Determinate / indeterminate

Guidelines

Do
첨부 올리는 중2 / 4개
값을 글자로 같이 둡니다. 틸·상태색 막대는 바탕 대비가 3:1 에 못 미칠 수 있어 막대만으로 뜻을 전하지 않습니다.
Don't
라벨·값 없는 막대 하나. 무엇이 얼마나 남았는지 알 수 없습니다.
Do0.3초 안에 끝나면 아무것도 보이지 않습니다. 10초를 넘기면 determinate 막대 + 「취소」, 끝나면 Toast 또는 Result section.
Don't한 화면에 스피너를 여럿 돌리지 않습니다 — 목록 전체가 처음 오는 중이면 Skeleton 하나로. 진행률을 모르면서 가짜 퍼센트를 올리지 않습니다.

Skeleton vs. Spinner vs. Progress

SkeletonSpinner · circle indeterminateProgress bar · circle
뜻무엇이 올지(구조)진행 중이라는 사실얼마나 남았는지
언제첫 진입, 목록·카드가 1–3초버튼 안, 새로고침·더 불러오기(기존 내용 유지)업로드·가져오기·에이전트 단계처럼 끝을 아는 작업, 10초 이상
문구없음3초가 넘으면 「불러오는 중」라벨 + 값 항상
취소없음없음10초가 넘으면 「취소」

Skeleton 페이지의 「Progress circle」은 여기의 Spinner(인라인·버튼)와 원형 indeterminate 를 가리킵니다.
