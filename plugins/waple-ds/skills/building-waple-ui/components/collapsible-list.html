Collapsible list

행 목록을 접는 두 가지 방법. 그룹 접기는 머리글을 눌러 그 그룹의 행을 감추고(사이드바 「사내 시스템」), 더보기 접기는 처음 몇 행만 보이고 「펼쳐보기」로 나머지를 엽니다(홈 「빠른 실행」). 둘 다 <details> 입니다.

Anatomy

오늘의 브리핑3결재 6건이 내 처리를 기다립니다오늘 업무일지가 아직 비어 있습니다잔여 연차 0일
  1. Group header (summary) — 라벨 t1 500 + 건수 + chevron, 40px, basement 바탕
  2. Rows — List row 그대로
  3. More row — 「펼쳐보기 · N개 더」, 열리면 목록 끝으로 내려가 「접기」

Guidelines

Do「더보기」로 감추는 행은 뒤쪽·덜 급한 것. 처리 대기가 있는 행은 항상 보이는 앞쪽에.
Don't그룹 안에 행이 둘뿐이면 접지 않습니다 — 접힘 자체가 한 번의 클릭 비용입니다.
Do남은 개수를 씁니다(「6개 더」). 사용자가 열지 말지 판단할 정보입니다.
Don't「펼쳐보기」가 페이지 이동(「모두 보기」)과 섞이지 않게 — 이동은 링크 문구·화살표로.
