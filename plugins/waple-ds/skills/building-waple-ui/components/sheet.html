Sheet

화면 가장자리에 붙어 밀려 나오는 떠 있는 면입니다. 목록을 떠나지 않고 한 건의 상세를 보거나(오른쪽), 좁은 화면에서 메뉴를 열거나(왼쪽), 모바일에서 고르고 확정할 때(아래) 씁니다. 배경·닫기·포커스 규칙은 Dialog 와 같습니다.

고객사 미팅 교통비와 식대입니다. 식대는 1인 한도 안이고 영수증 두 장을 붙였습니다. 승인하면 인사팀 검토로 넘어갑니다.

  1. Overlay — --bg-overlay. 누르면 닫힙니다
  2. Container — 가장자리에 붙는 면, --shadow-3. 오른쪽 360 · 480
  3. Header — 제목 t4 600 + 부제 t1 muted + 닫기 iconbtn. 고정
  4. Body — 여기만 스크롤합니다(Scroll area)
  5. Footer (선택) — 아래 고정, 주요 행동 하나 + 보조 하나
  6. Handle (아래 시트만) — 36×4 알약. 끌어서 높이를 바꾸거나 닫습니다

Behavior

항목규칙 — Dialog 와 같음
닫기× · ESC · 배경 클릭은 모두 「닫기」. 아래 시트는 아래로 끌어도 닫힙니다. 고치던 내용이 있으면 닫기 전에 확인 Dialog
포커스열리면 시트 안 첫 컨트롤(없으면 ×)로 가고, Tab 은 시트 안에서만 돌며, 닫히면 연 버튼으로 돌아갑니다
스크롤본문만 굴러갑니다. 머리·푸터는 고정, 뒤 페이지는 잠급니다
겹침시트 위 확인 Dialog 는 됩니다(상신·승인). 시트 위에 시트는 겹치지 않고 내용을 바꿉니다
모션가장자리에서 밀려 들어옴 --duration-normal --easing, 나갈 때 --duration-fast. 움직임 줄이기 설정이면 페이드만

Guidelines

Do목록 행을 누르면 오른쪽 시트로 상세를 엽니다. 닫았을 때 목록의 스크롤 위치와 선택이 그대로 남습니다.
Don't확인 한 번을 받으려고 시트를 열지 않습니다(Dialog). 시트 안에서 다른 화면으로 이동시키지 않습니다 — 이동은 페이지로.
Do푸터에는 주요 행동 하나(brand-solid)와 보조 하나. 모바일 아래 시트의 버튼은 폭을 채웁니다.
Don't아래 시트를 끌기로만 닫게 하지 않습니다 — 끌 수 없는 사람을 위해 × 를 함께 둡니다. 핸들만 두고 제목을 빼지 않습니다.
