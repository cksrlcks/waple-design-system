Waple Design System

Waple 에이전트·관리자 콘솔·앞으로의 UXIS 제품이 같은 언어를 쓰기 위한 디자인 시스템입니다. 회색 UI 에 강조는 하나 — 주색은 잉크(검정)이고, 틸은 선택·아이콘·포커스·글로우처럼 꼭 필요한 곳에만 씁니다. 이 사이트 자체가 이 토큰으로 그려집니다.

Foundations 색·타이포·간격·라운드·아이콘 — 바탕이 되는 토큰과 원칙 Components 버튼·입력·목록·표 — 실제 CSS 로 렌더링된 조각과 규격, 복사할 수 있는 HTML

디자인 원칙

1. 검정이 주인, 틸은 손짓주요 행동·선택은 잉크색. 틸은 화면당 한 곳 — 글로우 CTA·선택 상태·아이콘·포커스 링에만 씁니다.
2. 선보다 톤, 톤보다 여백구분은 여백 → 바탕 톤(basement) → 얇은 선 순서로. 그림자는 떠 있는 것(메뉴·다이얼로그·토스트)에만.
3. 상태는 여섯 어휘로success·warning·danger·info·neutral·sample. 색만으로 뜻을 전하지 않고 문구·아이콘과 짝을 짓습니다.
4. 실행 전에 확인에이전트는 조회·초안까지 스스로 하고, 상신·승인·기록은 Dialog 로 확인을 받은 뒤에만 실행합니다.

사용법

  1. tokens.css 를 프로젝트에 넣습니다. 값은 여기서만 바꾸고 이름은 유지합니다.
  2. 컴포넌트 CSS 는 semantic 토큰만 씁니다(--bg-brand-solid 처럼). --palette-* 는 semantic 이 없는 예외 상황에서만.
  3. 각 컴포넌트 페이지 맨 아래 HTML 을 복사해 시작합니다. 마크업과 클래스가 그대로 규격입니다.
  4. 아이콘은 Tabler Icons 만 씁니다 — Iconography.

명명 규칙

Color

색은 역할(semantic)로 씁니다. 팔레트를 직접 쓰는 것은 예외이며, 모든 글자색은 배경과 4.5:1 이상을 만족하도록 골랐습니다.

Brand ramp — 잉크

주색은 검정입니다. 주요 버튼·선택 칩·글자에 씁니다. 회색 램프와 같은 값이므로 「브랜드색」이 따로 눈에 띄지 않는 것이 의도입니다.

Accent ramp — 틸

틸은 강조입니다. 화면당 한 곳 — 글로우 CTA·선택 상태·아이콘 칩·포커스 링·안내 말풍선 틴트. 틸 위 글자는 검정(--fg-on-accent)입니다. 흰 글자는 대비 2.11:1 로 AA 미달이라 15px Bold 이상의 글로우 CTA 에만 허용합니다.

Guidelines

Do명령이 스무 개를 넘고 단축키가 있는 편집 화면에만 둡니다. 순서는 관례대로 파일 · 편집 · 보기 · 도움말.
Don't홈·설정·목록 화면에 메뉴바를 두지 않습니다 — Button 과 「더보기」 Menu 로 충분합니다.
Do모든 명령은 메뉴바에 있고, 자주 쓰는 것(굵게 · 기울임)만 툴바에 한 번 더 둡니다. 단축키는 메뉴에 적어 익히게 합니다.
Don't최상위 항목을 누르면 바로 실행되게 하지 않습니다 — 최상위는 메뉴를 여는 일만 합니다. 하위 메뉴는 한 단계까지.
Do지금 쓸 수 없는 명령은 비활성으로 남깁니다 — 메뉴 모양이 늘 같아야 위치로 기억합니다.
Don't상황마다 항목을 숨겨 메뉴 길이가 바뀌게 하지 않습니다.
